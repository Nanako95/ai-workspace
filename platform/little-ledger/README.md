# 小账本

移动端记账网站，支持网页内拍照识别、截图识别、多语言逐行 OCR、识别草稿逐条编辑/删除、账目多选删除、截图裁剪、用户名账户、密码登录、云端账目同步和货币转换。

分类支持当前账户独立新增和改名。设置会随用户名同步到云端；改名会同步当前账户已有账目，不会影响其他账户。

完整的 GitHub -> Render -> Supabase 配置、分类字段迁移、发布和数据清理说明见 [`DEPLOYMENT-GUIDE.md`](DEPLOYMENT-GUIDE.md)。

数据空间不足时，直接看 [`DEPLOYMENT-GUIDE.md` 的 Supabase 数据清理章节](DEPLOYMENT-GUIDE.md#supabase-数据清理)。正式使用建议先导出数据，再清理测试账目。

## 在线使用

直接打开：<https://little-ledger.onrender.com/>

手机端请使用这个 HTTPS 地址访问；拍照、截图识别和跨设备云端账目同步都从这里进入。

## 手机分享导入

在 Android Chrome/Edge 中打开在线地址后，可从浏览器菜单添加到手机桌面。安装后的“小账本”会出现在系统分享列表中；在相册或支付应用中分享截图，选择“小账本”，网页会自动进入逐行 OCR 确认页。

iPhone 可将网页添加到主屏幕，并使用“快捷指令”把照片或分享文字打开到小账本。不同手机系统对 PWA 分享目标的支持不同，因此网页内仍保留拍照识别和选择截图入口。分享文件只在浏览器临时缓存中传递，识别后立即删除，不写入手机相册。

### Android 使用步骤

1. 用 Chrome 或 Edge 打开在线地址。
2. 打开浏览器菜单，选择“添加到主屏幕”或“安装应用”。
3. 在相册、银行或支付应用中打开账单截图，点击“分享”。
4. 选择“小账本”，等待识别页面打开。
5. 检查逐行识别出的金额、分类、备注和日期，再点击“保存这笔记录”。

### iPhone 使用步骤

1. 用 Safari 打开在线地址，点击“分享”并选择“添加到主屏幕”。
2. 在“快捷指令”中新建快捷指令，接收“照片”或“文本”。
3. 添加“打开 URL”操作，使用小账本在线地址，并把快捷指令接收的文本拼接到 `?sharedText=` 参数；图片可先保存到文件后通过网页“选择截图”导入。
4. 在照片或支付应用的分享菜单中选择该快捷指令。
5. 回到小账本确认识别结果后保存。

### 其他入口与隐私

- 网页内的“拍照识别”适合直接拍摄纸质小票；“选择截图”适合从相册导入并逐张裁剪，裁剪框支持拖动位置和四角/四边自定义调整大小；“分享导入”适合从其他应用快速转入。
- “批量截图”支持一次选择多张图片；“连续拍照”支持连续拍摄多张后点击“完成并识别”，系统会把所有图片合并识别，生成多条待确认账目，再一次性提交到云端。
- 识别结果会过滤地址、电话、日期、票号等非消费行；每条待提交账目都可以修改金额、中文备注、分类、原始货币，也可以删除。识别到日文或日元符号时，原始货币自动设为 JPY，并在中文备注下保留原文。
- OCR 会把绿茶、緑茶、饭团、おにぎり、onigiri、三明治、サンド、抹茶、布丁等常见食品词归入当前账户的吃喝类；账目页支持勾选多笔后一次删除。
- 图片只在本次识别的浏览器临时缓存中传递，识别完成后删除，不写入手机相册；云端只保存确认后的结构化账目。
- 网站不能静默读取手机短信、银行 App、通知或全部相册内容，必须由用户主动点击分享、选择文件或授权摄像头。
- 分享目标需要先安装 PWA；如果手机或浏览器没有显示“小账本”，请使用网页内的拍照或选择截图入口。

## 本地运行

```powershell
npm start
```

打开 `http://127.0.0.1:4173`。

## 云端部署

GitHub Pages 只能托管静态前端，不能运行本项目的账户 API 和数据服务。请将整个仓库部署到支持 Node.js 持久化存储的平台，例如 Render、Railway、Fly.io 或 VPS，并设置 `PORT` 环境变量。生产环境应把 `data/ledger.json` 换成 PostgreSQL、SQLite 持久磁盘或其他数据库。

公网部署后必须使用 HTTPS，手机浏览器才会允许网页调用摄像头。项目包含 `Dockerfile` 和 `render.yaml`，可部署到支持 Node.js 的公网服务；部署成功后使用服务商提供的 HTTPS URL，手机点击该链接即可进入。图片只在浏览器内存中用于 OCR，不写入手机相册，也不会上传原始图片；云端只保存识别后的结构化账目。

汇率来自 Frankfurter 最新工作日参考汇率，服务端缓存 6 小时。账目录入时可选择原始货币和记账货币，系统按实时查询到的汇率转换并保存原始金额、目标金额和汇率快照。

## Supabase 免费云存储

1. 在 Supabase 新建项目。
2. 打开 SQL Editor，粘贴并运行 `supabase-schema.sql`。
3. 在 Project Settings -> API 复制 Project URL 和 `service_role` key。
4. 在 Render 环境变量中填写 `SUPABASE_URL` 和 `SUPABASE_SERVICE_ROLE_KEY`。两个变量只放在 Render，不要提交到 GitHub。
5. 配置完成后，Node 服务会自动使用 Supabase；未配置时仅作为本地 JSON 开发回退。

## 账户规则

首次输入未注册的用户名和至少 6 位密码会自动注册。已存在的用户名必须输入正确密码；错误密码会拒绝登录。登录成功后会保持 24 小时会话，刷新网页不需要重复登录；会话过期后需要重新输入密码。密码使用 Node.js `scrypt` 哈希保存，不保存明文密码。
