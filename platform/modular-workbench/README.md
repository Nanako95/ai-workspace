# Modular Workbench

一个配置驱动、可组合的个人工作台。它把页面、模块、布局和内容分开保存，用户可以在浏览器里创建页面、添加模块、编辑内容、拖动布局，并通过 JSON 备份和恢复整个工作台。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可。生产构建：

```bash
npm run build
```

## 核心能力

- 多个工作台页面
- 页面标签支持新建、重命名、修改图标和删除
- 每个页面支持带边框的模块分类标签，分类可以新增、重命名、改色和删除
- 模块库：文字卡片、待办、数据表格、文档、数据概览、时间提醒和自定义模块
- 编辑布局时可拖拽模块交换位置
- 模块设置支持重命名、重新分类、删除和内容持久化
- 编辑布局模式下，待办项、表格行、统计指标和自定义字段都支持单独添加、编辑和删除
- 自定义模块可组合标题、内容和字段
- 工作台设置支持名称、自动保存和紧凑布局，并保存到当前浏览器
- 浏览器本地保存，不依赖后端；旧版本数据会自动补齐分类结构
- JSON 导入和导出
- 响应式布局和深色模式

## 使用方式

- 使用顶部“工作台页面”标签切换页面；点击标签右侧的 `•••` 编辑或删除页面。
- 使用“模块分类”标签筛选模块；点击分类右侧的 `•••` 修改或删除分类，点击 `+` 新增分类。
- 点击模块右上角的 `•••` 编辑模块名称、内容和所属分类，也可以删除模块。
- 点击“编辑布局”后，可以直接管理模块内部内容：待办项、表格行、统计指标和自定义字段旁边会出现编辑、删除按钮，并提供添加入口。
- 文字卡片、文档记录和时间提醒的正文可以通过模块右上角的 `•••` 编辑；清空正文即可删除内容。
- 点击“设置”并保存工作台名称、自动保存和紧凑布局设置。重要数据仍建议定期使用侧栏“导出备份”。

## GitHub Pages

本项目是 Vite 静态站点，构建结果位于 `dist`。仓库根目录包含 `.github/workflows/deploy-modular-workbench.yml`：推送本项目后会自动构建并发布到 GitHub Pages。首次使用时，在仓库 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions。

当前数据默认保存在用户浏览器的 localStorage 中。若要多人协作或跨设备同步，下一阶段再接入账户和数据库服务。
