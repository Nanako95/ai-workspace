# 产品说明

## 当前能力

- 导入 UTF-8 CSV 或加载示例数据
- 查看行数、字段数、空值、唯一值、重复值和质量评分
- 新增、删除、启停清洗规则
- 拖拽规则修改执行优先级
- 一个规则同时选择多个字段
- 去除首尾空格、大小写转换、删除空值、查找替换、去重
- 搜索并预览清洗结果，导出完整 CSV
- 数据编辑支持按列筛选、单元格修改、批量修改、撤销和重做
- 质量报告支持勾选建议并一键优化，优化后同步刷新所有工作区和质量评分
- 数据分析支持分组字段、指标字段、聚合方式、筛选字段和值、展示字段和时间粒度配置
- 聚合表支持求和、平均值和计数；分析看板支持柱状排行、占比环图、时间趋势和明细排行
- 示例数据包含日期、地区、渠道、产品、分类、数量、金额、状态等字段和多个月份记录，便于演示筛选与趋势分析
- 作为 PWA 安装到电脑或手机，生产环境支持离线打开

## 数据边界

CSV 的解析、清洗和导出都在浏览器本地完成。当前版本没有账号、云端数据库或跨设备同步；跨设备使用依赖同一个已部署的网址，但每台设备各自处理本地文件。

## 后续建议

需要保存规则模板或跨设备同步时，再增加登录和云数据库。不要在没有隐私与权限设计的情况下上传原始 CSV。
