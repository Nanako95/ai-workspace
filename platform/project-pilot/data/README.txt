此目录保存项目管理应用的填写记录。

通过“启动项目管理.cmd”打开应用后：
- projects.json：当前全部页面设置、项目分类、关联系统、项目规划、依赖关系、节点和周会汇报记录，应用自动创建和更新。
- projects.backup.json：每次覆盖前保留的上一版完整数据。
- reports 文件夹：周会汇报页面保存的 PNG 图片；在历史记录中删除报告时，对应图片也会删除。

项目数据采用三级结构：项目分类 → 项目 → 项目规划。
分类、系统和页面名称请在“后台管理”中维护，不建议直接修改 JSON。

请勿在应用运行并保存时手工编辑这两个 JSON 文件。
迁移整个 project-pilot 文件夹时，请连同 data 文件夹和其中的 reports 文件夹一起复制。
