# Project Pilot

Project Pilot is a local project portfolio workspace for tracking plans, milestones, dependencies, risks, and weekly reports.

## Run locally

1. Install Node.js 18 or later.
2. Double-click `启动项目管理.cmd`, or run `node server.js` in this directory.
3. Open the URL printed by the server, normally `http://127.0.0.1:4310/`.

The application stores edits in `data/projects.json` and keeps the previous version in `data/projects.backup.json`. The committed data is synthetic demo content only. Replace it locally with your own data; do not commit confidential business records.

The bundled PDF is the original user manual. The repository copy intentionally excludes the bundled `runtime/node.exe`; use a local Node.js installation instead.
